# Recipe Editor Workshop (配方编辑工坊)

面向整合包作者的可视化 GregTech CEu Modern 配方编辑器。以游戏内指令打开图形界面，用于浏览配方库、新建与修改配方、禁用不需要的配方，并可将编辑结果导出为 KubeJS 脚本。

本模组不添加任何物品与方块，全部功能通过图形界面与指令实现。

## 环境要求

| 项目 | 版本 |
| --- | --- |
| Minecraft | 1.20.1 |
| Forge | 47.4.22 及以上 |
| GregTech CEu Modern | 7.5.3 及以上 |
| LDLib | 1.0.40 及以上 |
| Configuration | 3.1.0 及以上 |
| KubeJS | 2001 及以上（可选） |

KubeJS 仅在需要导出脚本时使用，未安装时其余功能不受影响。

## 指令

| 指令 | 作用 |
| --- | --- |
| `/rew` | 打开配方编辑器主界面 |
| `/rew gtm` | 打开配方总览，可多选后禁用或恢复 |
| `/rew reload` | 保存并让改动立即生效（重建配方包 + 触发重载 + 刷新快照） |
| `/rew save` | 将禁用表与草稿写入磁盘 |
| `/rew kjsexpt` | 将编辑过的配方导出为 KubeJS 脚本 |
| `/rew info` | 输出当前索引状态 |

## 界面说明

### 配方编辑器主界面

左侧为配方类型列表，右侧为该类型的配方列表，两列均可按中文名、拼音或 ID 搜索。列表右侧带有滚动条，可直接拖动。右键任意配方类型可新建该类型的空配方。

配方列表每一行左侧显示该配方首个产出的图标。物品使用物品自身的贴图，流体使用流体自身的贴图。

### 配方编辑界面

所有配方类型共用同一套编辑界面，由三张表组成：左侧输入表、右侧输出表、下方条件表。每张表分为物品与流体两段，可分别添加与删除条目，并设置数量与产出概率。条目较多时表格自动出现滚动条，可用滚轮或拖动滚动条查看。界面顶部可设置配方耗时、输入功率、电流，以及编程电路配置号。

条件表列出该配方的全部附加条件，条件内容以 GregTech 自身的序列化格式保存，因此其他模组新增的条件类型同样可用。

### 选择物品与流体

点击表格中的「+ 添加物品」或「+ 添加流体」进入选择界面，支持两种数据来源：

- **已注册物品 / 流体**：按中文名、拼音或 ID 搜索游戏内全部已注册内容。适合「知道要什么但手上没有」的情况。
- **从背包选**（仅物品）：点击右上角按钮切换，列出玩家背包中实际持有的物品。适合需要精确指定 NBT 的场合 —— 附魔书、药水、指定耐久的工具、写了内容的成书这类物品，仅凭物品 ID 无法区分，背包来源会连同 NBT 一并记录。

从背包选取的条目在表格中带有 `[NBT]` 标记。数量与产出概率取选择界面下方的输入框。

### 编程电路

输入表中有一个独立的「电路」配置项，填写 0 至 32 的配置号即可为该配方指定编程电路，留空表示不使用。编程电路属于「不消耗」输入，机器不会将其消耗掉。

### 不消耗输入

在概率框中填写 `0`，表示该输入为「不消耗」（催化剂），机器执行配方时不会消耗它，但仍需将其放入。编程电路与各类模具都通过这种方式表达。

### 配方总览

以多选列表的形式展示某个配方类型的全部配方。左键点击为多选，按 `Del` 键禁用选中项，按 `Ins` 键恢复选中项，右键单条配方可直接切换其启用状态。

被禁用的配方不会被加载进游戏，机器与 JEI 都不会再显示它们，但其完整内容仍保存在配置文件中，可随时恢复。

## 数据存储

编辑数据保存在游戏目录下的 `config/rew/` 目录中：

| 路径 | 内容 |
| --- | --- |
| `snapshot.json` | 配方库快照缓存，用于加快后续启动 |
| `disabled.json` | 被禁用的配方 ID 列表 |
| `drafts/` | 新建与修改后的配方，一条配方一个文件 |
| `export/` | KubeJS 导出结果 |

## 工作原理

模组通过 GregTech CEu Modern 官方提供的附属模组接口 `IGTAddon` 接入配方生成流程，不包含任何 Mixin。

- 禁用配方通过 `IGTAddon#removeRecipes` 实现，命中的配方在加载阶段被移出，不进入游戏的配方表。
- 新增与修改配方通过 `IGTAddon#addRecipes` 注入，与 GregTech 自身生成配方使用同一条数据包通路，因此执行 `/reload` 即可生效。

配方扫描在客户端进行，读取客户端已同步的配方库并缓存到本地，服务端不参与编辑过程。

## 配置文件

`config/rew.yaml` 提供以下选项：

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| `enableEditor` | `true` | 是否启用 `/rew` 编辑器 |
| `useSnapshotCache` | `true` | 是否复用配方快照缓存 |
| `alwaysRescan` | `false` | 是否每次启动都重新扫描 |
| `kubejsExportDir` | `kubejs/server_scripts/rew` | KubeJS 脚本导出目录 |
